# 单位换算 unit · 一个数换出全部单位

> 输一个数，长度 / 重量 / 温度 / 面积 / 体积 / 速度 / 存储 / 时间 / 压力九个类目一次换算完，点一行就复制。带市尺、市寸、斤、两、亩这些中式单位。

[English](README.en.md) | 中文

## 这是什么

换算页大多只给一个「从」和一个「到」，来回改两次下拉框才能看完。这页反过来：选定类目，右边直接把这一类里所有单位一次列出来，按数值从大到小排，输入的那一行高亮。

没有后端。九类单位存在一个数组里，每项是「中文名 + 符号 + 相对基准的倍率」，换算就是乘一次再除一次；温度不适用倍率，单独用两组公式走。重量、面积里带了市斤、市两、市尺、市寸、亩这些日常真会用、但国外计算器里找不到的单位。

细节上做了两件事：一是数字格式化，大于等于 1 的保留 8 位有效数字、小于 1 的保留 6 位，特别大或特别小的转成科学计数法，避免 0.0000001 和 1234567890123 把行撑爆；二是切换类目时给一个有意义的起步值（长度 1 米、温度 25 度、速度 60 公里每小时），打开就有东西看。

## 功能

- 九个类目：长度/重量/温度/面积/体积/速度/存储/时间/压力
- 一次列出该类目下全部单位，按大小排序
- 点任意一行复制那个数值
- 含市尺、市寸、市斤、市两、亩等中式单位
- 温度走单独公式，摄氏/华氏/开尔文互转
- 大数小数自动切科学计数法，不撑破布局
- 深色/浅色自适应 + 手动切换，窄屏单列
